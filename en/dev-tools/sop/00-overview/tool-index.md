# Tool index

The problem this page solves: **which ready-made tool to use for a given job**. Paths are relative to `开发工具/`; for scripts' applicable base avatars and ratings see `开发工具/README.md`.


| What you want to do | What to use |
|---|---|
| **Dispatch work to DeepSeek for execution** | `通用工具/dsh_task.js` — **the default action**, see [DSH dispatch](../01-automation-and-parallelism/dsh-delegation.md); has model pinning and after-the-fact verification built in |
| **Review what DSH did** | `通用工具/dsh_session.js` (list / show / grep / stats) — evidence comes from the logs, not from its own account |
| **Produce a texture tiering plan** (without opening Unity) | `通用工具/tex_tier_plan.py <工程>` — the full chain scene → prefab → material → texture; ⚠ the total is only an upper bound, the real gain is seen by rerunning PerfReport after the change |
| Unpack an asset pack into a project (preserving GUIDs) | `通用工具/unpack_unitypackage.py` |
| Multi-model cross falsification | `通用工具/agy_panel.py` (`--schema`/`--system`/`--raw` allow non-defect tasks) |
| One stable single-model call | **`~/bin/agy-task.py`** (the user's own bin, **not in the project**) — wraps the five pitfalls of headless agy; default model `gemini-3.8-flash-low`, a different lineup from this procedure |
| Check whether the toolchain can be upgraded | `通用工具/vpm_baseline_check.py <工程目录>` → baseline table `../_工具链基准.md` |
| **Check GUID collisions / broken links** | `通用工具/guid_uniqueness_audit.py <工程> --refs` — **hard criterion for stage 20** |
| The thing to review is too small in the image | `通用工具/img_tools.py diff-crop <出目录> <图...>` — uses a difference image to locate and crop to that region automatically, see [05](../05-multi-model-review.md) |
| **Which way does a blend shape actually move** | `通用工具/bl_keyprobe.py` / `bl_tilt.py` — Blender headless reads vertex displacement, in seconds, gives numbers; **don't guess from renders** |
| Render showcase shots + output spec JSON | `通用工具/AvatarPortrait.cs` |
| Same-camera A/B comparison | `通用工具/SceneViewShots.cs` |
| Performance baseline and texture tiering | `通用工具/PerfReport.cs` → `tex_tier_plan.py` → review the plan → `tex_tier_apply.py` → reimport/retest; for AAO use `FitAAO.cs` separately |
| Build aborted | `通用工具/FindDupComponents.cs`, `BuildBlockerScan.cs`, `FixAaoMergePhysBone.cs` |
| Menu generation | `菜单架构/MenuGen.cs` (edit the three tables `Slots`/`Accessories`/`SlotVendorParam`) |
| **Audit a project (data first)** | `通用工具/审查/`: T1 state driving (reads visibility and all blend shapes for every toggle combination; `Tools/AvatarAudit/Run Request` reads `<工程>/Library/AvatarAudit/request.json`), T2 fit probe, T3 turntable renders, T4 post-build menu export, T5 dependency matrix, part inventory (`Export Part Inventory`, including the key_follow same-name key check); deploy with `审查/perception/sync_audit.py <工程>` (add `--from-git HEAD` while DSH is editing the source), headless batch runs use `AvatarAudit.AuditBatch.ExportInventory`; documentation [audit/README.md](../../tools/audit/README.md) (paginated in `审查/docs/`) |
| **Declare "how it should be" and reconcile** | `通用工具/审查/perception/`: `decl_validate.py` (declaration validation), `decl_draft.py` (draft a declaration from the project), `key_follow_verdict.py` (same-name key mismatch verdict), `verdict.py` (declaration × measurement reconciliation), `writers_static.py` (static writer graph), `pose_frames.py`/`pb_static.py`/`pose_plan.py` (poses and PhysBone); documentation [perception/README.md](../../tools/audit/perception/README.md) |
| **Clear audit leftovers before delivery** | `通用工具/审查/perception/sync_audit.py --strip`, `strip_audit.py --check/--apply` (deletes `Assets/AvatarAudit` and unity-mcp in the manifest) |
