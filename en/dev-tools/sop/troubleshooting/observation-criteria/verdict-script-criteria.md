# Criteria for verdict scripts

> Split out of [The shape of a criterion](shape-of-a-criterion.md) (2026-09-19, the original page exceeded 10 KB). Read when writing audit/verdict scripts. This page is the canonical source for "how to write verdict scripts"; diagnosing the shape of a criterion is in [The shape of a criterion](shape-of-a-criterion.md), and broken observation channels/probes/directions are in [The criterion itself may be broken](criterion-may-be-broken.md).

## ⚠ Which mesh "is the body" in a tool can't be identified by name and vertex count alone (2026-09-19)
- Incident: the same-name key check on Project G and Project F (Kipfel base avatar) identified the face mesh `Body` (7539 vertices, weights all on head/eyes) as the body, and the real body `Body_Base` (5451 vertices) was missed — all 303/375 keys written to the "body" were expression keys, and the result was entirely void.
- Criterion: among candidates (`Body_b`/`Body_base`/`Body` etc., case-insensitive), the one whose **skin weights cover the foot bones and torso bones** is the body; only if none qualifies fall back to geometric heuristics. Task AM has fixed `AuditPartInventory.FindBodySmr` accordingly; the analogous fixes for T-10 poke and T2 body=auto are in task AY.
- Checkable question: "Is the exported `body` path something like Body_base/Body_b? Are the keys written to the body all eye/mouth?" — if the latter, it was misidentified.

## If you can't decide, write "can't decide"; test exemptions against true positives (2026-09-19 acceptance of DSH AX/AZ)
- **Trigger**: when writing a verdict script and encountering "can't attribute / no data / names don't match", or when adding exemption conditions to suppress false positives.
- **Ask**: "Is the reason this item lands on pass evidence, or 'no evidence so treat it as fine'?" "Would a known true defect of the same shape also be swallowed by this exemption?"
- **Practice** (the analogous problem at the probe layer: `null`/`0` read as a legitimate value → [The criterion itself may be broken](criterion-may-be-broken.md) "A probe must not let 'missing' silently become a legitimate value"): anything unattributable goes into a separate `undecidable` column; don't convert it to pass/fail by assumption (AX's verdict judged unattributable visibility as invisible and passed it). After adding an exemption, run a true positive of the same shape (Project A `sailor.outer_shlink`) to confirm it is still reported — AZ's "doesn't count if the key is on any visible outfit" exempted it too. Trade-off: better to list one more "can't decide" row than to silently let it through.
- **Define the words of conclusion labels first**: the same kind of evidence gets the same label. "Baked into the mesh" (vertices already changed) and "default weight non-zero" (weight set on the renderer) are two different things; AV labeled four projects' face sculpting with the two phrasings interchangeably — without a vertex comparison you may not write "baked in".
- **Loosen the match pattern before counting**: when counting "how many", first count with a loose pattern (case-insensitive `*BlendShare*.asset`), then cross-check with a different method; AW counted 6 projects with a strict pattern, actually 9.
- **Judge plugin semantics by code, not comments**: for cross-version comparisons read the branch actually executed (which level the `if (Set)` wraps); AW inferred C3 from comments and got it wrong.

- **When checking residue by guid, get the guid before deleting** (2026-09-19 acceptance of BE): once the script directory is deleted, the `.cs.meta` goes with it, and a subsequent `--check` can't get the guid and reports "clean". If it can't be obtained, read the `.meta` from the git baseline (`git show HEAD:<路径>.meta`); if still unobtainable, report "can't decide" — reporting ok is not allowed.
- **When counting files, don't let the pipeline split names on spaces**: vendor paths often contain spaces (`LUNALICE_White01_Mono/Shoes_Leg Ribbon`); `for f in $(...)` and `xargs` without `-0` both count one file as two; use `find -print0 | xargs -0` or Python.
- **Fallback guesses must not be written into conclusion fields**: if no basis can be obtained, fill in "can't decide" and put the guess in a separate field (BG wrote the guess "vendor prefab counts as sock, scene-added counts as shoe" into `sock_owner`). **Stop words include only state suffixes and base avatar names** (`off`, `on`, `rurune`), not part words (`hood`) — that would swallow hood-type true positives (2026-09-19 acceptance of BN).
- **Don't guess open-toe/closed-toe from product images or part names**: measure the front-back difference between the frontmost point of the sock/shoe foot and the base avatar's toe tip + whether the foot has a boundary loop (opening) (2026-09-19 Project C: only the Violet sock is open-toe). The Motion Time radial wrap-around criterion needs "does the last key have a new on/off relative to the previous key", otherwise a last key that merely holds is misjudged (Project F).

## Reading authoritative artifacts (merged from section one of [The shape of a criterion](shape-of-a-criterion.md); criterion boundaries must be traced back from artifacts, see "Root fix" in that section)
- To get paths from `.anim`/`.prefab` YAML, **don't use `grep "path:"`** — long values wrap, and continuation lines without a colon are silently dropped; use a **YAML parser**. When a long quoted path wraps, the continuation line gets folded into a space: if you see "an extra space" in a path, read it with a YAML parser before concluding "the path is misspelled" (2026-09-19 acceptance of BL).
- In scenes/prefabs, scripts **appear only as guids** (`m_Script: {fileID: 11500000, guid: …}`), so searching by class name never finds them: first read the guid from the project's `<脚本>.cs.meta`, then search (AZ's stripping check searched by literal class name, so real scenes always reported clean).
- Changes to prefab instances are in the `PrefabInstance`'s `m_Modifications`; reading only the source prefab misses them.
- Negative samples must iterate the **full set of actual samples**, not just known violating rows (otherwise missed detections can never be measured).
