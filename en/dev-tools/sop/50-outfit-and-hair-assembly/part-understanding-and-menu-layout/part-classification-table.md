# Part classification table: criteria, default menu handling and exceptions for each class

**Classification answers “what is it in the layering of the outfit”; it does not directly decide switch granularity** — granularity is decided by visual weight ([three axes](three-axes-and-naming-trap.md)). The user's 09-22 “classify it as underwear, but don't toggle it together with the panties” is an example of the two being separate 〔explicit〕 (relayed in `lt/作业清单_全部未完成.md:965`).

There is also a separate axis for **fitting method** (full set / built-in BoneProxy / ring-shaped / accessory with its own skeleton / surface-attached / held / static part inside the skeleton, [03 Assembly and conflict rules](../../03-assembly-and-conflict-rules.md)); it and this table do not replace each other.

Classify by how it is worn, not by its name (`A/Assets/Editor/AvatarGen/MenuGenA2.cs:434-436` 〔corrected〕). `A/…/` below always means `A/Assets/Editor/AvatarGen/`.

**Terminology**: the Chinese word `胸衣` has two meanings; this set of subpages always writes them separately — **bra**: cup-style underwear; **corset**: コルセット, a garment that cinches the waist. Nipple covers and pasties are neither bras nor corsets.

**How to layer outerwear vs tops** (a criterion proposed by this page 〔convention〕, pending H-03 calibration): on the same body segment, if removing it (image C “full set - none”) reveals another garment, it is the outer layer; if the two don't cover each other, decide by how the vendor's showcase images wear them. The names in parentheses in the “Criterion” column are only hints; don't match against the table by name.

## Cross-project inconsistencies (state which one this order uses when creating the file; don't copy by default)

- **Underwear switch granularity**: Project G uses one switch for top and bottom pieces (`G/_审查准备_20260918.md:55`); Manuka splits into `内裤关` and `bra关` (`hist/H4-Manuka/_工程档案.md:62` 〔practice〕); Project A only covers the bottom piece (`A/…/MenuGenA2.cs:450-453`); Project C merges several pasties, tattoo stickers and chest-strap-type small items with the panties into one (`C/_物品状态全表_20260909.md:57-63`; what these items actually are was never verified with renders).
- **Same-type items classified without a recorded reason**: of the leotards in Project D's two outfits, one is classified as underwear and one as top (`D/_审查准备_20260918.md:57,60`).
- **Neck**: Project C puts the choker under Top and the necklace under Hangings (`C/_物品状态全表_20260909.md:68-69,113-114`); Milfy has a separate “Neck accessories” switch (`B/菜单结构.md:31`).
- **Misleading switch names**: Project D's “下着” controls the shorts (Japanese “下着” = underwear) (`D/_审查准备_20260918.md:60-61`); Project F's “Skirt” originally controlled only the shorts (`F/_审查准备_20260918.md:82`).
- **Props classified as garments**: Esmera's phone visibility hangs under “Outerwear” (`D/_审查准备_20260918.md:58`).
