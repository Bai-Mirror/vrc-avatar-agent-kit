# 上传后自测清单（模板，2026-09-23）

**为什么**：编辑器构建后口径 ≠ 游戏端（远端量化、同步位、镜子/第一人称、其他人视角）。09-22 工程B Play/构建终检全过，上传后用户报两项游戏内问题。这份清单让「真机口径」成为交付的最后一格，由用户在游戏里勾。

**怎么生成**：从 `期望.json` 的 states 逐条转成一行；每个轮盘每档一行、每个开关开/关各一行；再加下面固定项。写进交付说明末尾「上传后请自测」一节。

## 固定项（每单都有）
- [ ] 镜子里与第一人称各看一次：默认装、全脱、每套衣装各一档
- [ ] 让一个朋友（Friends 权限）看你：轮盘每档切换后他那边跟着变（同步位）
- [ ] 轮盘拖到最末档与最首档：都能选到，不跳回
- [ ] 每个开关连点两次：开→关→开，没有「关了开不回来」
- [ ] 换套装后旧套装的小件（袜、手套、饰品）没有残留
- [ ] 表情/面捕开着做 3 个表情：舌头、眼睛、嘴部小件没穿出
- [ ] 动骨：头发/裙/链子摇一摇，没有炸开或卡进身体
- [ ] 性能等级与参数量与交付说明一致（SDK 面板）
