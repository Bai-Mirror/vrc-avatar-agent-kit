# 捏完之后脸上「凹凸」怎么归因、怎么修

**触发时刻**：用户说「捏脸让网格出现凹凸的纹理，影响观感」，或你自己在 cavity/toon 渲染里看到褶皱棱线。
2026-09-20 工程B v2 实做，之前輝夜（工程A）也撞过同一类问题但**没归因成功**
（`工程A/Assets/_Work/嘴部褶皱定性.md` 的「捏脸前」基线读不出来，24.5°/21.1% 那张表**没有对照、结论不成立**，别照抄）。

## 先否掉两条看似合理的错路

**① 不是「自定义法线陈旧」。** 直觉是：形态键改了几何，厂商烘好的自定义拆分法线没跟着转，所以明暗错乱。
实测 Milfy `Body`：厂商自定义法线**本来就偏离几何法线 mean 37.7°、p99 149.9°，34332/42334 个角超 5°**——
那是一整套手绘法线场（层叠脸卡片的常规做法），几何法线转那 2–11° 对它几乎无影响。
把自定义法线按 Rodrigues 旋转跟随后重渲，**toon 图 B−C 差 p99 = 0.0/255**，纯无效操作。
> **可查问句**：动手补偿法线之前先量一次「自定义法线 vs 几何法线的夹角」。
> **它大（>20° 量级）就说明法线是手绘的、与几何解耦，跟随旋转必然无效**；它小才值得跟随。
> 同类教训：[改色的亮度补偿是数学恒等](../40_贴图配色/素体贴图与改色手法.md)。

**② 不是「表面被拉皱」。** 逐顶点 Laplacian（umbrella）幅值：捏脸后 p99 从 4.757 mm **降到** 4.675 mm，
增量 p99 仅 0.132 mm。整体曲率没变差，所以别去做全局平滑——那只会把捏脸抹平。

## 真因：局部挤瘪 + 层间互穿。用三个指标一起定位

都拿「厂商原版 basis」与「basis + 捏脸位移」两组坐标算，**同一套面表**：

| 指标 | 怎么算 | 工程B v2 实测（厂商 → 捏完） |
|---|---|---|
| **网格自交** | `BVHTree.FromPolygons(...).overlap(self)`，剔掉共顶点的相邻面对 | 632 → 666，**新增 114**（66 对是 `Face_transparent` 卡片互穿） |
| **面法线转角** | 面法线（Newell/叉积和）前后夹角 | **30 个面 >25°**，最大 49.69° |
| **面积塌陷** | `A_after / A_before` | **60 个面 <0.5**，最小 **0.129** |
| 法线翻转 | 夹角 >90° | 0（翻转是更严重的一档，没到） |

> ⚠ **这三项测不出「阶梯横纹」那一类。** 它们量的都是「**面自己**转了多少 / 塌了多少 / 穿没穿」，
> 而眼睑上那种分层横向明暗条带是**相邻面之间的断阶**。2026-09-20 我只用这三项修完，
> 下眼睑的硬暗线消了，**上眼睑的阶梯条带一条没动**（三项在该带全部未超标：转角 p99 9.03°、面积最小 0.882、无新增自交），
> 被 agy 在实机着色下一眼看出来。**必须加第四项**：

| 第四项 | 怎么算 | 为什么必要 |
|---|---|---|
| **Δdihedral（相邻面二面角变化）** | 每条被两个面共用的边，量捏脸前后两面法线夹角之差 | 直接对应明暗断阶，是 toon 着色真正看到的量 |
| **位移场高频 `\|Laplacian(D)\|`** | 用边邻接算 D 的 umbrella 算子 | 做**种子**用，比 Δdihedral 更早暴露问题区 |

**阈值怎么定：拿没被碰过的区域当对照。** 工程B实测（Δdih 边>5° 的条数 / p99 / `\|Lap(D)\|` p99）：
上眼睑 34 / 5.43° / 0.4445mm；下眼睑 200 / 7.76° / 0.4683mm；嘴周 83 / 6.55° / 0.227mm；
**额头（全程没动）0 / 0.07° / 0.0386mm**。对照带几乎为零 → 取 `Δdih>3°`、`\|Lap(D)\|>0.06mm` 就够分。

**种子集要写成**：新增自交面 ∪ 转角>20° ∪ 面积比<0.75 ∪ **`\|Lap(D)\|>0.06mm` 的顶点** ∪ **`Δdihedral>3°` 的边的顶点**。
工程B补完后：上眼睑 34→**10**、下眼睑 200→**14**、嘴周 83→**11**，三项硬门槛仍全为 0，代价是扰动 p99 从 1.19 升到 1.37 mm。

⚠ **平滑的混合边界会给原本干净的区域引入一点高频**（对照带 `Δdih p99` 0.07°→0.34°、`\|Lap(D)\|` 0.039→0.171mm）。
**把对照带一起列进验收表**，确认它的 边>5° 仍为 0；涨到有边超标就说明 `r_blend` 铺得太开了。

**三者会落在同一条带上**，按 z 分段统计就能定位。工程B是 z 1080–1128 mm 的**下眼睑—脸颊带**；
上眼睑带（p99 9.03°、面积最小 0.882）与嘴周带（9.55°／0.688）相对干净。

**逐键归因**：只开一个键跑一遍同样三项，就知道是谁干的。
工程B：`eyelid_corner_up = −1.0` 一个键 30 个塌陷面、`eyelid_corner_down = 1.0` 另 10 个；
自交头号来源是 `face_child = 0.38`（单键 64 处）。
> **负值就是反向线性外插**，是厂商没设计过的区间，最容易出这个；满幅（±1）的键优先查。

## 修法：局部层间同步位移（修不是重置）

原理：相邻卡片层拿到了**不同的位移**，层间距只有零点几毫米，差值一大就互穿。
所以要平滑的是**位移场**，不是几何；而且只在出事的邻域里平滑。

1. **种子** = 新增自交面 ∪ 转角>20° 的面 ∪ 面积比<0.75 的面，取其全部顶点。
2. **影响权重** `w(v)`：v 到最近种子的 3D 距离 `d`，`w = smoothstep(1 − d/r_blend)`，`d ≥ r_blend` 时为 0。
3. **平滑**：`D̃(v) = Σ_j exp(−(d_ij/(0.6·r_smooth))²)·D(j) / Σ w`，邻域用 **3D KDTree 半径 `r_smooth`**
   （**不是网格连通性**——必须跨过不相连的卡片层，否则层间根本同步不了）。
4. `D(v) ← D(v)·(1−w) + D̃(v)·w`，迭代 1–3 轮。

**参数是扫出来的，不是拍的。** 工程B扫了 5 组，判据＝三项指标归零且对捏脸扰动最小：

| r_smooth / r_blend / 轮 | 新增自交 | >25°面 | 面积<50% | 面积最小 | 对捏脸扰动 max/p99/mean |
|---|---|---|---|---|---|
| 4 / 10 / 1 | 16 | 0 | 0 | 0.552 | 1.43 / 0.73 / 0.11 mm |
| 8 / 16 / 2 | 10 | 0 | 0 | 0.692 | 2.31 / 1.08 / 0.20 mm |
| **10 / 18 / 2** | **0** | **0** | **0** | **0.726** | 2.54 / 1.19 / 0.23 mm |
| 12 / 20 / 3 | 4 | 0 | 0 | 0.730 | 2.64 / 1.47 / 0.29 mm |

**取舍**：再大不会更好（12/20/3 反而回升到 4），因为平滑半径超过卡片间距尺度后开始互相带偏。
**达不到全零怎么办**：优先收 `r_blend`（少动点）而不是加轮数（加轮数是对同一批点反复平滑，扰动涨得快）。
**验收还要加一条**：总自交数不得高于厂商原版（工程B 629 < 632）——否则你只是把问题搬了个地方。

## 结论要送证伪，而且它会挑出你阈值以下的残留

工程B这次用 `agy_ask` + Workbench cavity 三联图（A 原版 / B 未修 / R 已修，同机位同光同材质）。
它确认了「B 有褶皱、R 修掉了、R 没抹平造型」，但**证伪了「彻底消除」**：
