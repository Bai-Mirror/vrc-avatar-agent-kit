# 厂商的 N 个变体，**不一定两两不同**

> 从 [`问题定位/素材与材质排查.md`](../素材与材质排查.md) 拆出的子页。接手自主页原第九节；「补充」里的空材质槽仍留主页。

### 触发

**看到厂商一个目录下摆着一排同名不同色的材质**（`glass_water/Blue/purple/pink/green/white`），
准备把它们一一对应到菜单的 N 个档位时。

### 问

**「这 N 份，两两之间到底差在哪个字段？」**

不要假定「文件名不同 ⇒ 效果不同」，也不要假定「差别在 `_Color`」。

### 答错了怎么办

跑一遍**属性差异全表**：遍历 shader 的每个属性，只打印
「六份之间取值 `Distinct().Count() > 1`」的那些。这张表就是"颜色"的全部内容。

### 证据（2026-09-08 工程C · Aquaglass 六色玻璃）

- `_Color`：**`water` 与 `Blue` 完全相同**（都是 `#241F82`）、**`purple` 与 `white` 完全相同**（都是纯黑）
  —— 六个色号在 `_Color` 上只有 **3 个** 不同值
- 真正区分 `water`/`Blue` 的是**法线波纹贴图**，区分 `purple`/`white` 的是 **matcap 贴图**

**这直接决定菜单怎么做**：如果按"动画写 `_Color`"实现，六档里有**两对是死档**
（拨过去什么都不变）；只有走「换整份材质」才能把贴图差异也带上。

### 判据

生成完档位，做**两两可分**校验：把每档的效果归约成集合两两比对，
或者逐档渲图算 MD5。**任意两档相同 = 有死档。**
见 [60 · 生成完轮盘必须回读校验「任意两档效果不同」](../../60_菜单与动画层/生成器实现坑.md)。
