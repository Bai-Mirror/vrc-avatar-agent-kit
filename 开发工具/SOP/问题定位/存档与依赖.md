# 问题定位 · 存档与依赖可复现性

> **存档能不能打开，比存档有多大重要。**
> 2026-09-01 拉取历史工程时发现：**10 个个人工程里有 4 个已经打不开了。**

## 症状

Unity 启动几秒后退出，返回码 1，日志里一句：

```
An error occurred while resolving packages:
  Project has invalid dependencies:
    jp.lilxyzw.liltoon: The file [<云盘同步目录>\VRC\liltoon\package.json] cannot be found
```

## 两种不可复现的依赖写法

**① `file:` 指向工作区外的本地目录**

路径里往往还带着**旧账户名**（如 `<云盘同步目录>/...` 这类用户目录）。
换机器、目录移走、云盘不同步了，工程立刻打不开。

**② `git#<branch>` 分支依赖**

```json
"jp.lilxyzw.liltoon": "https://github.com/lilxyzw/lilToon.git?path=Assets/lilToon#master"
```
**能打开只是因为 `Library/PackageCache/` 里有当年 clone 的副本。**
删掉 Library 就再也复现不出同一份代码 —— 实测两个工程从同一个 `#master`
分别拿到的是 **2.3.2 和 1.10.3**。

## 归档前必查

```bash
grep -E '"(file:|https?://)' Packages/manifest.json
```
命中就必须转成 VPM 版本号再打包。

## 查当年真正用的是哪个版本

**`Library/PackageManager/ProjectCache`** 是文本，记录了当时解析出的每个包。

⚠ **`version:` 字段在 `name:` 之前**。往后找会取到相邻条目的值 ——
我第一次就把某工程的 AAO 误读成 `3.2.1`（实为 `1.9.8`）。

`source:` 是 `UnityEditor.PackageManager.PackageSource` 枚举：

| 值 | 含义 |
|---|---|
| 1 | Registry |
| 2 | Builtin |
| 3 | **Embedded**（在 `Packages/` 里，VPM 装的就是这个） |
| 4 | **Local**（`file:` 指到工作区外） |
| 5 | LocalTarball（`.tgz`） |
| 6 | Git |

## 转换做法

1. 包体落到 `Packages/<包 id>/`
   —— **优先用工程自己 `Library/PackageCache/` 里那一份**（当年真正构建用的字节），
   没有才从版本相同的兄弟工程拷
2. `Packages/manifest.json` 里那行**删掉**（VPM 管的包不进 UPM manifest）
3. `Packages/vpm-manifest.json` 写 `dependencies` + `locked` 两处版本号
4. `packages-lock.json` 对应条目清掉，让 Unity 重新解析
5. 原文件留 `.bak-<日期>`

**用不上的死依赖直接摘掉**，别硬凑版本
（实例：某工程依赖 AAO 1.9.8，本地没有该版本，而**那个场景里一处 AAO 组件都没用**）。

## 别把 lilToon 的自改写当成"包被污染"

同为 lilToon 2.3.2 的两份拷贝，5 个 shader 文件内容不同、**且两边互有新旧**。
那是 **lilToon 自己按渲染管线改写 `#pragma skip_variants`**（`Editor/CurrentRP.txt` 是它的记号），
导入时会自动重写，**拷哪份都行**。

## 旧存档能不能删：只比文件数不算数

`7z l -slt` 会输出每个文件的 **CRC32**，不解压就能比 `(路径, 大小, CRC)` 三元组。

**分三类判：**
- **完全重合**（0 缺失 0 不同）→ 可删
- **差异只在可再生物**（`Library/`、`Assets/*__Generated/`、`Packages/*.temp/Builds/`、
  插件升级后被删的旧版源码）→ 可删
- **有独有的非再生内容** → 先弄清那是什么。
  > 实例：某"副本"里 7 个材质比新包**更新**，看着像丢了活；
  > diff 出来是 **7 个材质被批量换成 `VRChat/Mobile/Toon Standard` + 渲染队列钉成 2000**
  > —— 那是一次**失败的移动端转换**，不是要保的内容。

**shader GUID 备查**：`e765db0afa7ecfc44ade2e4e2491f65a` = VRChat/Mobile/Toon Standard。

## 传输与校验通路

- 包直接打到 `$ARCHIVE_ROOT/`（`kit.env` 配置的存档目录）
- **对存档目录里那一份跑 `7z t`**，删本地源之前必须验它，不是验打包前的源
