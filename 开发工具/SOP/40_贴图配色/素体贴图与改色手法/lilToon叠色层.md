# lilToon 叠色层：厂商常留着闲置遮罩，可局部改色而不动一个像素

> 从 [`40_贴图配色/素体贴图与改色手法.md`](../素体贴图与改色手法.md) 拆出的子页。接手自「素体贴图与改色手法」的 lilToon 叠色层一节；与「优先离线合成」的分工仍留主页。

### lilToon 叠色层：厂商常留着闲置遮罩，可局部改色而不动一个像素

`_UseMain2ndTex` / `_UseMain3rdTex` 是**带遮罩的叠色层**。不少厂商已把遮罩画好放在
包内的遮罩目录里（常见有只盖眼球圆的眼部遮罩、只有一道眉毛笔触的眉毛遮罩、发网遮罩；
用前先量覆盖范围，确认它只盖目标部位）。开一层就能只染眼球：

```
_UseMain2ndTex       = 1
_Main2ndTex          = 那张遮罩本身      ← alpha 决定作用范围
_Main2ndBlendMask    = 同一张
_Color2nd            = 目标色（alpha = 强度）
_Main2ndTexBlendMode = 见下
```

与上文「优先离线合成」的分工：**有厂商遮罩、只改颜色** → 叠色层（零像素改动、可逆、改 `_Color2nd` 就能出档）；
**要换整张图、或没有遮罩** → 离线合成。

- **⚠ 遮罩名字会骗人**：`Eyebrow` 遮罩不含睫毛（覆盖率只够一道眉）。别按名字假定范围，**先量 alpha 覆盖率**，对一下目标部位的 UV 岛面积
- **⚠ 没遮罩 ≠ 只能在压平贴图上做像素手术** —— 先找分层源文件（下文「有 PSD/CLIP 源文件时」）。我据此在压平 PNG 上改过睫毛，被用户当场否掉

**混合模式枚举 Normal(0) · Add(1) · Screen(2) · Mul(3)**，出处 `lilLanguageManager.cs:145` 的 `sBlendModes`；
厂商自带的脸材质这个槽用的是 **3**。方案写「乗算」而按语义顺序猜填 `0` = Normal = **直接替换**，
整只眼被平涂成一个色盘，虹膜层次与瞳孔花纹全没了。**枚举值去源码查，别按顺序猜。**

**乗算永远提不亮。** 「颜色有点深」时把 `_Color2nd` 往白靠是错的：乗算只能压暗，往白靠只是让压暗量趋近 0，
**回不到基底之上**。实测四档 `#FFB0C8`→`#FFE8F0`：**V 恒定 0.62，只有 S 从 0.42 掉到 0.23** ——
那是去饱和，肉眼分不清「变淡」和「变灰」，HSV 一测就露馅。

| 想要 | 旋钮 | 代价 |
|---|---|---|
| 真提亮 | 换 **Screen(2)**：α0.25 / 0.45 → V 0.76 / 0.82 | 把虹膜洗白，S 掉到 0.20，瞳孔与虹膜的对比糊平 |
| 少压暗、保住结构 | **乗算 + 降 α**（多数时候最好） | 提不亮，只是压得少 |
| 往白靠 | — | **假动作**：V 不动、只丢饱和 |

调深浅前先说清要动的是 **V 还是 S**；出数报 HSV 三个分量，别只贴 hex。

自己派生的遮罩贴图必须关 sRGB（`importer.sRGBTexture = false`），否则通道值被 gamma 拧一遍。
