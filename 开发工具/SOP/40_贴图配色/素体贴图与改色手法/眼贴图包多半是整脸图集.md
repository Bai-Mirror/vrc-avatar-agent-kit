# 「眼贴图包」多半是整脸图集：能不能直搬，看眼盘 bbox

**触发时刻**：客户/自己挑中了某个眼睛贴图包，准备把它接到素体的脸材质上。

## 先看清它是什么

Booth 上叫「◯◯眼睛贴图」的包，**里面往往是 4096² 的整张脸图集**（`_MainTex`），不是单独的虹膜小图。
因为素体的脸是一张图集：头皮、眉毛、睫毛、嘴、装饰件、以及**左右两个眼球圆盘**全挤在一张 4096² 上。
所以「换眼睛」在文件层面就是「换整张脸图」——**会把妆容一起换掉**。

## 判据：两张图的眼盘包围盒是否逐像素一致

同一素体的官方/第三方贴图，UV 是共用的 → **眼盘在图集里的位置、尺寸必须一模一样**。

做法（工程B Milfy 实做）：
1. 在两张图里分别分割眼盘（先看眼盘外圈是什么颜色，按该色设一个 RGB 阈值，逐行取 min/max x 填充）；
2. 比 bbox。一致 → **可以直接按坐标搬运，零对齐误差**；
3. 再做**左右对称校验**：`(图宽 − 2) − L.x_max ≈ R.x_min`。对不上说明分割被中间的睫毛条之类污染了，收紧 x 范围重来。

实测结论：某眼部贴图包内多个变体的眼盘位置与工程在用的脸图完全相同 → 同一 UV，直搬；
另一个包初看布局不同（眼盘更大、没有侧边小片）——但见下节，这个「不同」后来被证明是误判，实测差异很小。

## 只换眼、不换妆：按眼盘掩膜合成

别整张替换。实测两张同 UV 的脸图在**眼盘之外**仍有大面积明显差异
（妆容、腮红、装饰件都不一样）——整张换会连脸一起变。

做法：`out = 新图·w + 原图·(1−w)`，`w` = 眼盘掩膜做 5 px 高斯羽化。
UV 不同的包（如 Prism）：把它的眼球 alpha 包围盒 `resize` 到本素体的眼盘 bbox，再套同一个掩膜。
> **对齐基准可以从网格拿**：把形态键（`pupil_*` / `highlight_*`）有位移的顶点对应的 loop UV 多边形栅格化成掩膜，
> 就能拿到**瞳孔/高光在图集里的精确位置**，不用目测。注意这类掩膜给的是「瞳孔」，**眼盘本身要另外分割**。

## 先问「这个包是不是给本素体的」——**是的话直搬，一个像素都别缩**

2026-09-20 我在这里连犯两次错，代价是两轮返工：
把一个**本来就是给 Milfy 的**贴图包（Prism 系列，库里路径与包名都带素体名）
当成「别的素体的图」，先按眼球包围盒缩放了一次，被 agy 指出偏移后又按虹膜框做了仿射——
**两次都是在修一个不存在的问题**，结果虹膜被缩小、下方留出一条空白带，比直搬难看。

**判据（先跑这两条，再决定要不要缩放）**：
1. **来源**：包在素材库里的路径与包名带不带本素体名？商品页的对应素体写了什么？
   主库 `<素材库>/.booth-archive/manifest.json` 的 `items[].avatars` 直接给支持素体列表。
2. **alpha 覆盖率**：把本素体的眼盘掩膜与该图的 `alpha>8` 求交。
   **原生对齐的特征是「覆盖率 ≈100% 且 bbox 只比眼盘外扩几十像素」**——外扩的是 **UV 出血**，不是错位。
   上节那个「初看布局不同」的包实测正是这种情况 → 原生。

**原生 → 直搬**：`out = 新图·w + 原图·(1−w)`，`w` = 眼盘掩膜羽化。不缩放、不平移、不做仿射。

**确属别的素体 → 才做虹膜框仿射**：两边各自分割虹膜（原生图＝眼盘内的非外圈色；外来图＝
`(sat>30) | (lum<170)` 排除近白柔光），x/y 独立缩放把外来虹膜框映射到原生虹膜框
（`a=1/sx, c=src_x0−tgt_x0/sx`，整张 `Image.transform(AFFINE)` 后用眼盘掩膜裁），
**做完重新分割一次虹膜框对账**（中心差 <10 px、尺寸差 <5%）。
⚠ 注意「眼球 alpha 包围盒」**不能**当对齐基准：包围盒里含多少出血/外围柔光是各家自定的。

## 给证伪模型的前提，决定了它会证伪什么（同一轮的教训）

我给 agy 的提示里写了「右列是从另一素体移植过来的，**可能没对准**」。
它于是老老实实去找移植误差，报回「虹膜偏大 5–10%、瞳孔偏高、下缘有硬圆边」——**三条都对**，
但那是**我自己缩放造成的**，不是素材本身的问题。它没有、也不可能质疑我给的前提。

> **可查问句**：我写给证伪模型的提示里，有没有一句是「我的假设」而不是「可观测的事实」？
> 有的话，先把那句也列成待证伪项；至少再问它一遍「如果这个前提是错的，你的结论会怎么变」。
