## 二、谁判什么

| 问题 | 交给谁 | 为什么 |
|---|---|---|
| 图上是什么、贴/穿在哪、什么材质感 | 视觉模型：DeepSeek 盲标，agy（Gemini）证伪 | 「有没有 / 是不是 / 哪个更 X」可派（[DSH模型与视觉能力](../../01_自动化执行与并行/DSH模型与视觉能力.md) 第二节规则①） |
| 显不显眼、是不是展示图主角 | 视觉模型的套装级比较轮（盲标与敏感图第二节）＋商品说明与标签 | 逐件看图比不出「哪个更显眼」，要放在一起问 |
| 盖住哪段身体、被不被外层遮住、与邻件距离、有几件、齐不齐 | 几何与数据：主导骨、差异像素、逐顶点距离 | 实测精确计数 23→24、6 px 错位判成「完全对齐」，是确定性失败（[DSH模型与视觉能力](../../01_自动化执行与并行/DSH模型与视觉能力.md) 第二节能力表） |
| 厂商把它和谁分一组、参数 `true` 是显示还是隐藏 | 读厂商目录里的 clip 与菜单资产 | [03_装配与冲突通则](../../03_装配与冲突通则.md) |
| 视觉权重最终定级、彩蛋、默认值、菜单文案 | 用户拍板，Claude 出候选 | 作者 09-22；`CLAUDE.md` 强制准则 4 |

## 三、送审怎么写

- **写明哪些是有意设计**（服装自带头饰、内衣＋丝袜的造型），并附厂商展示图；不写的话，模型会把相邻突出物都算进声明的类别 —— LUNALICE 的蝴蝶结、Violet 的发夹被认成「第二套耳朵」（[证伪任务设计](../../05_多模型评审规程/证伪任务设计.md)）。
- 问「这是什么 / 在哪 / 哪个更显眼」，不问「有没有两个 X」。
- **先盲标、后对名**，两轮分开派；两轮对不上本身就是要记的发现（[三轴与望词生义](三轴与望词生义.md) 第三节）。

## 四、证伪

- 「是什么」「可见条件」「视觉权重」都是视觉结论：写进图鉴、或据此编菜单之前，送 agy 证伪；送审输入是**我们的结论**，不是「工具正不正常」（`CLAUDE.md` 强制准则 1；规程 [05_多模型评审规程](../../05_多模型评审规程.md)）。敏感图可以外送（作者 09-22 13:3x 拍板，盲标与敏感图第三节）。**送 agy 的图也用涂黑副本、中性文件名，题面不写商品名**：H-03 批 A–C 送了原图，叠印的材质名漏进了判定（Gemini 理由里出现「corset line」，题面没有这个词，`pkg/The Velour/_agy/H03_批B_部件图_结果.json`）；题面写了「The Velour」，批 C 首跑就把黑短裙说成「粉色丝绒（Velour）」（`H03_批C_部件图_结果.json`）。
- agy 调用的产物路径写进图鉴「证据」栏；DeepSeek 与 Gemini 结论不一致 → 交用户看图，不自己裁（[60_菜单与动画层](../../60_菜单与动画层.md) 步骤 3 的 STOP）；但属于上面第二节「几何与数据」那一行的（遮没遮住、有没有、什么颜色），先用像素、材质、几何裁，裁得了就写明数据、不必交用户（H-03 V6、V8、V10，`pkg/The Velour/部件图鉴.md`「证伪结果」）。
- **纹样、印花类（蕾丝还是豹纹、有没有印花）先查源贴图，再送模型**：材质 `_MainTex` 的 guid → 贴图 `.meta` → png。H-03 Velour 靴子正面是白色花卉蕾丝贴图被材质 `_Color` 压暗成近黑，DSH（P08 两轮）和 Gemini（批 C 两跑）都看成豹纹；贴图一查就定，再送 agy 两跑确认（`pkg/The Velour/_agy/H03_批D_*`）。**触发时刻**：模型对花纹的说法互相冲突，或和材质名对不上。**可查问句**：这块图案的源贴图看过没有？材质 `_Color` 有没有把它染深？**取舍**：读两个文本文件、看一张图，比多跑几轮模型便宜；贴图找不到（程序化纹理、多层混合）再退到放大渲图＋模型。
- **送 agy 优先送「仅部件」或同机位拼图**（09-22 H-04）：含人物的整套图 Gemini 5/5 撞权限墙；缩成单句论断、换仅部件图通常能过，还不过就记「撞墙未判」，别反复烧。
- **题面抬头按图种写**（09-22 H-05）：三联图（A/B/R 同机位）、仅部件单图、厂商平铺商品图各配各的抬头与 schema，不共用；H-05 Vend 批套用「三联图」抬头整批判错，换抬头重跑才对。**可查问句**：这批送的是几张、什么图？抬头写的图种与之一致吗？
- **套装比较的三个口径补丁（候选，H-04/H-05）**：① 商品号是**素体**商品（如 Kaguya 原装）时，先问「这套服装在哪几张展示图里被专门展示」，只拿那几张比；② 「基础层＝展示图里看不见」对**被裁到画外但常穿**的件落不下去，候选改为「焦点 0 且可见 < 半数」，写进图鉴时标「候选」；③ 厂商图只有**平铺商品图**（无人物；H-05 NamaikiMaid 后备库仅 1 张、无 `booth_tags`）时「焦点 / 可见几张」落不下去：比较轮不排焦点，图鉴权重栏标「展示图不合格」，定级只靠商品说明与用户拍板，不硬凑。
