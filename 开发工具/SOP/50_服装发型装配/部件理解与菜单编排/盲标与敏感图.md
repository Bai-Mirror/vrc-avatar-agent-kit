# 盲标与敏感图：第 3 步怎么派

**为什么要盲标**：工具在每张图左上角叠印「商品名 / 渲染器路径 / 视图」和「tris / mats=材质名」（`开发工具/通用工具/部件图鉴/PartAtlasCapture.cs` 文件头注释；`part_atlas_overlay.py:95` 原地覆盖，不留无字原图；H-02b 重拍的 300/300 张都叠过字，`A/_交付/部件图鉴_拍摄报告.md:90`），文件名也带部件名（`<序号>_<部件名>_仅部件-正面.png`）。模型看到部件名里的 bra、briefs、corset 就会照名字答 —— 这正是用户要防的望词生义。工具改成另存无字原图之前，按下面的办法处理。

## 一、盲标（第一轮）

1. **做匿名副本**，放 scratchpad，不放进 `素材包说明/`：涂黑叠字框，按匿名编号改名 `P05_v1.png`…；编号对照表只留在本地，不写进任务书。
2. **任务书里不出现网格名、材质名、商品名**。只问：「这是什么？贴/穿在身上哪里？和谁连着？在整套里显不显眼？」
3. **出口判据**：把本套全部网格名、材质名拼成一个正则，grep 任务书和输入图路径清单，结果为 0。

涂黑用下面的函数。叠字框的宽度随字数变（`part_atlas_overlay.py:77-82`），所以整条横带都涂黑。有/无成对的两张，要用同一条横带：

```python
from PIL import Image, ImageChops

def band(im):   # 叠字框下沿：沿 x=12 往下走，直到不比左上角背景暗
    bg = sum(im.getpixel((5, 5))) - 60
    y = 12
    while y < im.height and sum(im.getpixel((12, y))) < bg: y += 1
    y += 2
    if y > 160: raise ValueError("叠字框量出 >160，停下人工看")
    return y if y >= 80 else 110    # <80＝没量准（叠字至少两行≈83），改用固定 110

def masked(path, y1):
    im = Image.open(path).convert("RGB"); im.paste((0, 0, 0), (0, 0, im.width, y1)); return im

def diff_px(a, b):   # 有/无 两张：同一条横带涂黑后，数非零像素
    y1 = max(band(Image.open(p).convert("RGB")) for p in (a, b))
    d = ImageChops.difference(masked(a, y1), masked(b, y1)).convert("L")
    return sum(1 for v in d.tobytes() if v > 0), y1
```

实测 Velour 72 张：多数量出 83～105（两到三行字）；乳贴件「在身上-侧面」那张量出 14，框下面压着东西、没量准。内裤件「整套-有/无」那两张量出 55 **只盖住第一行，第二行 `tris=… / mats=<材质名>` 露在横带下**（x=12 处框底下压着亮色袖子，走到 55 就停了）——09-22 H-03 盲标涂完拼接触印样才看出，原判「仍盖住」是错的；门槛因此从 `<50` 提到 `<80`（叠字至少两行，最矮约 83）。`>160` 报错停下。
**涂完必看**：把全部匿名图顶部 200 px 拼成接触印样看一遍，横带下不许有字。出口判据只 grep 任务书与路径，**查不到图里的残字**，这一步不能省。

## 二、对名（第二轮）与套装级比较

- **对名**：把网格名、材质名、厂商开关名发给它，和第一轮的描述对照；对不上的写进图鉴「名字线索」栏。
- **套装级比较**（单开一个会话）：输入是厂商展示图（`.booth-meta.json` 的 `images`，Velour 21 张全是 `kind=main`）加上各部件的图 C「整套-有」（H-02b 起是按部件取景的那张），部件用匿名编号。问：「这些图里，编号部件哪几件是画面焦点？按显眼程度排序，并说出各自在几张展示图里看得见。」定级判据见 [三轴](三轴与望词生义.md) 第一节。
- **分批**：每个部件一个会话，≤8 张；比较轮单独一个会话。Velour 一套有 54 张部件图（H-02b 加了全身对比后是 72 张）、21 张展示图，一次全塞进去容易超时，也容易读漏。
- **核验**：用 `dsh_task.js --images` 派工，看它逐张核验的 PASS；被拒的 `read_image` 不算读到（[DSH静默失败](../../01_自动化执行与并行/DSH静默失败.md) ⑤）。只看会话日志里有没有调用，是会漏的旧口径。

## 四、差异像素（工具不算，要另算）

- 用第一节的 `diff_px(有, 无)`。**不涂黑直接相减，会把「有」「无」两个字算进去**：本页编写时（09-22）实测 Velour 9 对图，不论全身取景还是 H-02b 的按部件取景，叠字区每对都恰好 418 px。这和 工程B 判「看不见」用的量级相当（≤253 判看不见，482、686 看图定，`B/Assets/_Work/_60内衣.md:6-20`）。
- 要看差在哪：`python 开发工具/通用工具/img_tools.py diff-crop <输出目录> <有.png> <无.png>`，自动裁出热区。
- 工程B 那组数没写画幅和像素阈值（`_60内衣.md` 全文 20 行），和 768² 图不可比。**768² 图要重新标定，标定之前差异像素只作旁证。**
- 例：H-02 时 agy 判 Velour 乳贴在整套默认造型里被黑色抹胸完全遮住（`A/_施工记录.md:935`），涂黑叠字后差异却不为 0：全身取景 429 px，按部件取景 2153 px（阈值 >0）。H-03 已定：是露了一条边和前扣（修正前），不是阴影——特写、Gemini（V9）和 Σ|Δ|>40 的 1075 px 一致（`pkg/The Velour/部件图鉴.md`「证伪结果」）。
