# DSH 执行要点：任务书固定行、未决时的默认动作、接入点

## 一、任务书固定行（装配、编/改菜单、建图鉴三类都带）

```
- 先按 Booth 商品号查档：grep -rl '<商品号>' 开发工具/素材包说明/*/部件图鉴.md；结果按方法页第一节四态处理。
- 装配任务缺图鉴不停工：挂上并确认渲染后拍照建档，菜单与收缩键不定稿。编/改菜单任务缺图鉴时停下，回报 NO-PARTS-DOC <商品号> <商品名>。
- 重拍前看 开发工具/素材包说明/<商品名>/部件图/：非空且本任务书没写「覆盖同一素体」就停下，回报 ATLAS-DIR-NOT-EMPTY。
- 建档按 开发工具/素材包说明/_部件图鉴模板.md 全字段填；不适用写「N/A＋原因」，不许删字段。
- 标注分两轮：盲标用匿名副本（遮掉叠字框、改名 P<nn>_v<k>.png），任务书里不写网格名、材质名、商品名；对名轮再给名字。带图一律 --model vision 加 --images，逐张核验 PASS 才算读到；每个部件一个会话、≤8 张。
- 敏感件（按图 A 与几何判：覆盖胸、下身的贴身小片；不按名字判）**可以外送**（作者 09-22 13:3x 拍板）；模型拒答时退到几何与差异像素，并在图鉴「证据」栏写明哪几张被拒。
- 菜单与冲突建议每条带「路径:行号」和来源级（明/纠/惯/厂/实）；视觉权重、默认值、彩蛋只写「建议＋理由」，标「待 Claude/用户定」。
- 解压厂商 zip/unitypackage 一律 `-C <临时目录>`，**不许解在 cwd**（09-22 PuNyaNya 在工作区根留下 75 个 GUID 目录）。
- 嵌套派 DSH（给部件开视觉会话）时 `~/.dsh` 在沙箱里只读：`HOME=<工作区临时目录>`（拷入 `.dsh/profiles` 与凭据）＋`DSH_BIN=<绝对路径>`，**收尾删掉影子凭据**；见 [DSH能力与改造](../../01_自动化执行与并行/DSH能力与改造.md) 嵌套派工一节。
  - 多路嵌套并发时核验块可能报「认不出会话」退出码 2（09-22 H-05 6/6），回答其实是好的：先手解 `<影子HOME>/.dsh/sessions/**/session.jsonl.zstd` 核 `read_image` 次数再判；根因（09-22 22:40 查实并修）：嵌套时 `dsh_task.js` 继承了 `DSH_HOME=<真家目录>`、`HOME=<影子目录>`，按 DSH_HOME 找会话，而子进程按影子 HOME 写会话；已改为按子进程的 `$HOME/.dsh/sessions` 找（旧版在同环境复现 FAIL、新版 PASS；H-05 复验嵌套 28/28 认领成功）。
- 厂商开关若不在 MA MenuItem 组件里，而是**预制的 VRCExpressionsMenu 资产**（`menuToAppend`）＋ `MA_Animator/` 目录下的 FX，拍照工具的「厂商 clip / 开关组件」两栏会是 0/空（09-22 兔子居家服），要人工补读这两处。
- 产物：图鉴写进 开发工具/素材包说明/<商品名>/；本任务不改工程菜单。派工带 --record <触发本次建档的工程>，施工记录记在那个工程；图鉴用 ws_git 提交，提交信息带商品号。
```

`--record` 的规矩见 `CLAUDE.md` 强制准则 5、6；遮字与分批的做法见 [盲标与敏感图](盲标与敏感图.md)。

## 二、未决时的默认动作

方法页与子页里标「候选」「待审」「未决」的，只有下表几项；DSH 碰到就按「默认」列做，并在图鉴「未决」栏写一行。**表外的规则必须照做**；表外又确实没写到的情况，按「写建议＋标待定、不落工程」处理。

| 未决项 | 在哪 | 默认 |
|---|---|---|
| 乳贴口径推广到别的套（卖点 → 单独开关） | [菜单编排决策](菜单编排决策.md) 决策一 | 单独、并组两案并列写，标「待定」 |
| 权重定级判据（比较轮的阈值） | [三轴](三轴与望词生义.md) 第一节 | 按候选判据给级，标「候选」；算出 Velour 乳贴不是卖点，就回报「判据待改」，不改用户定的级 |
| 遮胸门要不要收卖点件 | 菜单编排决策 冲突① | 写进图鉴冲突栏作候选，本任务不改工程 |
| 敏感图外送 | [盲标与敏感图](盲标与敏感图.md) 第三节 | **已定：可外送**（作者 09-22 13:3x） |
| 卖点件默认穿/脱 | 菜单编排决策 决策四 | 跟厂商预制件默认 activeSelf、展示图里的穿着状态走，标「待定」（Velour 乳贴已定：**默认开**，作者 09-22 13:3x） |
| 768² 图的差异像素阈值 | 盲标与敏感图 第四节 | 只作旁证，不据此单独下「看不见」 |
| 彩蛋素材采不采用 | [彩蛋项编排](彩蛋项编排.md) | 图鉴只列素材，不进菜单 |
| 身体/脚部形态键 | [冲突检查单](冲突处理检查单.md) C08、C09、C11 | 只写「候选键＋候选宿主＋待验」 |

## 描述常漏「小而显眼的金属件」（09-23 H-05 抽查两连中）
- Rogue Noir `Bat` 漏了棒头两道带刺金属箍、酒红/白分色；Peridot `2. Belt` 漏了带面一排银色圆铆钉——都是 Gemini 抽查时指出、DSH 盲标与对名轮都没写。
- **写描述时逐项过一遍**：主色/分色 → 材质（皮/布/金属/透明）→ 金属件（扣、环、链、铆钉、刺、吊牌）→ 图案/印花 → 形状关键词。金属件对观感权重影响大（高光抢眼），缺了会把「点缀」误判成「基础层」。
- 抽查口径：Claude 每本至少抽 1 个部件，把描述原文＋仅部件/在身上两张图送 Gemini 问「有没有遗漏明显特征」，补的内容在行内注「Claude 抽查＋Gemini」。
