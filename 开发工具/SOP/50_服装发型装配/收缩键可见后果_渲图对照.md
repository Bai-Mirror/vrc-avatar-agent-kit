# 收缩键「缺了有没有可见后果」：冻结 Animator 渲 0/100 对照

> 上级：`脚型与收缩键归属.md`。本页只管一件事：数据上发现某个收缩键从没被写（比如厂商层 weight 0、写者缺失），要判断它缺了看不看得出来。
> 复跑脚本（C-12）：`开发工具/通用工具/审查/unity/Editor/T3ArmFreeze.cs`，菜单 `Tools/AvatarAudit/T3 Arm Freeze (Edit Mode)`；请求 `Library/AvatarAudit/t3_arm_freeze_request.json`，示例 `审查/unity/examples/t3_arm_freeze_request.json`（工程F `t3_arm_A3` 原件数值）。

## 触发
T1 读数显示某个身体收缩键（`Shoulder_OFF`、`Upper_arm_OFF` 这类）在「衣服穿着」时是 0，而厂商 clip 本意是 100。

## 做法（2026-09-18 工程F实测）
1. T1 `reset:none` 把头像摆到目标状态（衣服穿着；**挡在前面的外层先关掉**，比如针织背心盖住肩部就先关背心）。
2. `execute_code` 关掉头像根的 `Animator.enabled`（冻结，否则下一帧就被动画写回），手动 `SetBlendShapeWeight` 取 0，T3 渲一组；取 100 再渲一组，相机参数完全相同。
3. **正对照**：同样两组值、`only_renderers:["<身体>"]` 只渲身体，差异像素要明显（工程F ≈35,000 / 512²）。正对照不过，说明键没生效或相机没对准，后面的「0 像素」不能用。
4. 穿衣两组逐像素比（阈 24/255）。
5. 做完**恢复**键值并重新打开 Animator。

## 判据与取舍
- 穿衣组差 0（或只有几十个散点）＝ 这个姿势下看不出来 → 不急着修，记「待机无可见后果，动作中待动作批」。
- 差异成片 → 缺键有可见后果，要补写者（MA ShapeChanger 挂在衣服上，或补 clip）。
- **看图前先看取景**：`hide_renderers` 至少关头发、尾巴、挎包；工程F第一轮后视图被头发整个挡住，差 0 毫无意义。拼一张 2×2 小图先扫一眼再比。
- 结论仍要送 agy 求推翻（题目写「我的结论」）；agy 指到与被测键无关的问题（比如缝线描边），要用「0/100 两组是否逐像素相同」来区分。

## ⚠ Play 里别做「换网格」对照（2026-09-19 工程D实测）
NDMF/AAO 构建后，渲染器的骨骼数组可能被重排、身体被合进 `$$AAO_AUTO_MERGE_SKINNED_MESH_n`。运行时把 `sharedMesh` 换成资产里的原网格，蒙皮就错了（量到的「距离」全是 100 mm 量级的垃圾值，渲图甚至逐像素不变）。**要比「换网格前后」，在编辑模式用场景真实骨骼做**：`BakeMesh` 后量件到身体的最近距离（分位数）；只改形态键值的对照才可以在 Play 里做。Play 里按名字找身体也要注意它可能已被合并改名。
- **几何量统一来源**（2026-09-19 验收 AY）：身体与件都用 `BakeMesh`（带当前形态键权重、读完还原），产出写明 `geometry_source`；别一边用 sharedMesh 原始顶点、一边用蒙皮后顶点——两种空间混用，距离没有意义。多帧形态键取满权重帧。
- **BakeMesh 的两个参数与「两端」**（2026-09-19 验收 BF）：之后要乘 `localToWorldMatrix` 就必须 `BakeMesh(m, true)`（useScale），否则缩放≠1 的渲染器被缩放两次；「键 0 / 100 两端」要真的把身体键设 0 烘一次、设 100 烘一次、再还原原值，不能拿「当前权重」和「当前+100」冒充两端。
- **量 MA Delete 的删除区只能在编辑模式**（2026-09-19 验收 BQ）：进 Play/构建后 MA 已处理身体网格——常驻 Delete 物理删顶点、可开关的用 NaN 骨骼隐藏（MA `ReactiveObjectPass`），Play 里的 BakeMesh 量不到「本该删的区」。删除区按写者自己的 `m_threshold` 取，不自定阈值；写者挂在没有网格的容器上要报出来，不许静默跳过。

## 收缩 SC 挂在哪一件（2026-09-20 工程D Velvet China）
厂商把 8 个收缩键的 ShapeChanger 挂在**整套根**上：部件开关（袜子/外套等）关掉后键仍是 100，露出的部位（小腿、脚踝）塌成细线。触发：审一个收缩 SC 时先问「它的宿主是整套根还是覆盖那块皮肤的件？」；是整套根就按覆盖关系拆到各件（袜=膝/小腿/踝/足/趾，袖套=肘/前臂，衣身=肩），逐个「单关一件」渲图。开口鞋（踝带/浅口）别让鞋收踝与足背——露出的那段会塌；只收趾，脚背从鞋口露出属设计（对照「袜开」参考图判）。
