# 工具索引

这页解决的问题：**做某件事该用哪个现成工具**。路径相对 `开发工具/`；脚本的适用素体与评级见 `开发工具/README.md`。


| 要做什么 | 用什么 |
|---|---|
| **把活派给 DeepSeek 执行** | `通用工具/dsh_task.js` —— **默认动作**，见 [DSH派工](../01_自动化执行与并行/DSH派工.md)；自带模型写死与事后核验 |
| **复盘 DSH 干了什么** | `通用工具/dsh_session.js`（list / show / grep / stats）—— 取证靠日志，不听它自述 |
| **出贴图分档方案**（不开 Unity） | `通用工具/tex_tier_plan.py <工程>` —— 场景→预制体→材质→贴图 全链路；⚠ 总量只是上界，真实收益看改后重跑 PerfReport |
| 把素材包解进工程（保 GUID） | `通用工具/unpack_unitypackage.py` |
| 多模型交叉证伪 | `通用工具/agy_panel.py`（`--schema`/`--system`/`--raw` 可做非缺陷型任务） |
| 一次稳的单模型调用 | **`~/bin/agy-task.py`**（用户自己的 bin，**不在工程里**）—— 封装了 agy 无头的五个坑；默认模型 `gemini-3.8-flash-low`，与本规程编成不同 |
| 查工具链能不能升级 | `通用工具/vpm_baseline_check.py <工程目录>` → 基准表 `../_工具链基准.md` |
| **查 GUID 撞车 / 断链** | `通用工具/guid_uniqueness_audit.py <工程> --refs` —— **20 阶段硬判据** |
| 要评的东西在图里太小 | `通用工具/img_tools.py diff-crop <出目录> <图...>` —— 用差异图自动定位并裁到该区域，见 [05](../05_多模型评审规程.md) |
| **形态键到底往哪变** | `通用工具/bl_keyprobe.py` / `bl_tilt.py` —— Blender headless 读顶点位移，秒级、给数值，**别用渲图猜** |
| 渲染定妆照 + 出规格 JSON | `通用工具/AvatarPortrait.cs` |
| 同机位 A/B 对比 | `通用工具/SceneViewShots.cs` |
| 性能基线与贴图分档 | `通用工具/PerfReport.cs` → `tex_tier_plan.py` → 审核方案 → `tex_tier_apply.py` → 重导/复测；AAO另用 `FitAAO.cs` |
| 构建被中止 | `通用工具/FindDupComponents.cs`、`BuildBlockerScan.cs`、`FixAaoMergePhysBone.cs` |
| 菜单生成 | `菜单架构/MenuGen.cs`（改 `Slots`/`Accessories`/`SlotVendorParam` 三张表） |
| **审查一个工程（数据优先）** | `通用工具/审查/`：T1 状态驱动（逐开关组合读显隐与全部形态键，`Tools/AvatarAudit/Run Request` 读 `<工程>/Library/AvatarAudit/request.json`）、T2 贴合探针、T3 转台渲图、T4 构建后菜单导出、T5 依赖矩阵、部件盘点（`Export Part Inventory`，含 key_follow 同名键检查）；部署用 `审查/perception/sync_audit.py <工程>`（DSH 正改源码时加 `--from-git HEAD`），无界面批跑用 `AvatarAudit.AuditBatch.ExportInventory`；说明 [审查/README.md](../../通用工具/审查/README.md)（分页在 `审查/docs/`） |
| **声明「应该怎样」并对账** | `通用工具/审查/perception/`：`decl_validate.py`（声明校验）、`decl_draft.py`（从工程起草声明）、`key_follow_verdict.py`（同名键失配判定）、`verdict.py`（声明 × 实测对账）、`writers_static.py`（静态写者图）、`pose_frames.py`/`pb_static.py`/`pose_plan.py`（姿势与 PhysBone）；说明 [perception/README.md](../../通用工具/审查/perception/README.md) |
| **交付前清掉审查残留** | `通用工具/审查/perception/sync_audit.py --strip`、`strip_audit.py --check/--apply`（删 `Assets/AvatarAudit`、manifest 里的 unity-mcp） |
