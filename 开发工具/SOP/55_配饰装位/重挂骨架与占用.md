# 重挂骨架与「占用」判定

这页解决两个容易搞错的判定：**要重挂骨架时，改的是不是网格真正绑定的那一份**；
以及**判一个位置被占没被占时，遮挡不等于占用**。
两条都属于「静态看着全对、动起来或换一套就露馅」的那一类。

## ⚠ 重挂骨架时：**改的必须是网格实际绑定的那一份**

### 触发
**当你要给一个已经挂进场景的配饰换挂点、或调整它的骨架位置时。**

### 问
**「四个 SkinnedMeshRenderer 的 `m_RootBone` / `m_Bones` 指向的，是不是我正要改的那些 Transform？」**

### 答错了怎么办
按 **fileID**（不是名字）找到网格实际绑定的那一份，**改它**；
把另一份删掉或停用。**不要重绑 `m_Bones`** —— 重绑比改父级危险得多。

### 证据（2026-09-07 工程C · GOTHIC ROSE 狐耳）

预制体被 unpack 成散装 GameObject 后，一次「重新挂载」建出了**两份结构完全相同的骨架分支**：

| | 激活 | 父 | 网格绑它吗 |
|---|---|---|---|
| 分支 A | **0（被停用）** | Head（旧挂点，带 1.2579 m 偏移） | **是** |
| 分支 B | 1 | 素体根（新挂点，位置正确） | 否 |

结果：**网格跟着被停用的 A 走，飘在头旁边；位置正确的 B 什么都不驱动。**
而世界坐标判据量的是 B —— **两条距离判据全过，图却是错的。**

> 执行那一路**自己判对了**「只有一份被网格实际引用」，但**停用时停错了那一份**。
> 这是**识别与动作用了不同的标识**（识别用 `m_Bones`，动作用名字）造成的。

### 由此得到两条规矩

1. **unpack 之后一律按 fileID 操作。** 散装之后同名节点会成对出现
   （本例 14 个骨节点每个都有两份同名），靠名字选必然出错。
2. **「重挂骨架」这类操作，判据要包含「网格跟过去了没有」** ——
   世界坐标只证明**骨**到位了，证明不了**网格**跟着骨走。
   唯一判据是**渲图**：骨对了但网格没跟过去，是这一类操作最典型的失败态。

### 怎么从场景 YAML 查（不必开 Unity）

```python
# 1) !u!1 GameObject 块 -> m_Name / m_IsActive
# 2) !u!4 Transform 块  -> m_GameObject / m_Father
# 3) !u!137 SkinnedMeshRenderer 块 -> m_RootBone / m_Bones（都是 Transform 的 fileID）
# 把 3 的 fileID 拿到 2 里查父链，就知道网格绑的是哪一份、那一份激活没有
```

## ⚠ 遮挡 ≠ 占用：骨权重和包围盒看不出「开口」

### 触发
**当你要判「这件配饰被那件衣服 / 鞋袜挡住了没有」（脚甲随鞋袜隐藏、颈饰被衣领盖住、耳饰埋进发型）时。**

### 问
**「我用的是占用判据（权重占比 / 包围盒重叠），还是真的看了一眼？」**

### 答错了怎么办
**强制显示被遮物 + 渲一张特写**：被遮物 `enabled = true`，遮挡物照常显示，机位对准被遮物。看得见就是没遮住。
便宜、决定性、不需要调阈值 —— 「看得见吗」是闭式问题，渲图回答的是它，不是审美。

### 证据（脚甲 × 五套鞋袜）

事先定了两条几何判据，**两条都失效**：

| 鞋袜 | 趾骨权重占比 | 包围盒重叠 | 实拍 |
|---|---:|---:|---|
| 鱼嘴高跟鞋 | 7.31% | 100% | **大脚趾外露，甲清晰可见** |
| 连脚丝袜 | 22.26% | 100% | 趾尖不透明 → 真遮住 |
| 闭口鞋 | 19.01% | 100% | 真遮住 |
| 鱼嘴平底鞋 | **N/A**（16 个网格 `isReadable=false`） | 100% | **趾尖开口，甲外露** |
| 闭口靴 | 10.50% | 100% | 真遮住 |

- 包围盒**毫无区分度**：5/5 全报 100%（鞋帮 / 绑带 / 花边贴近趾骨就把它骗满）
- 权重按 1% 阈值五套全过 → 照判据五套脚甲全会被藏掉，**其中两套是错的**
- `sharedMesh.isReadable=false` 读不出权重：如实报 N/A，**不要拿包围盒单条顶替**

### 边界
- **不推翻**「穿模互斥」用占用 + 层深 —— 穿模确实是占用问题；只推翻用占用判**遮挡**，两者分开处理
- 「遮住 → 隐藏」的门接在鞋 / 袜的**部件**开关上（[60 · 按遮挡状态的层](../60_菜单与动画层/层序与压制.md)），且**每双鞋逐个判**，不按整套衣服一刀切
- 两个方向都是可见缺陷（错藏 = 客户买的东西不见了；错留 = 甲尖从鞋面穿出），**没有保守默认**，只能逐双渲图定
