## 镜像件：缩放的**符号**必须沿用原型

厂商左右成对的件常用 `localScale = (-1, 1, 1)` 做镜像（本工程左腕饰就是）。
装位算出来的是**大小**，符号得从原型取回来：

```csharp
var src = PrefabUtility.GetCorrespondingObjectFromSource(obj.gameObject) as GameObject;
Vector3 sgn = 符号(src != null ? src.transform.localScale : obj.localScale);
obj.localScale = new Vector3(s * sgn.x, s * sgn.y, s * sgn.z);
```

写成 `Vector3.one * s` 会把镜像抹掉 —— 左腕上戴了个右腕的件，缎带缠绕方向、荷叶边旋向全反。
**而且**：拼旋转时局部方向也要先过一遍符号（`Vector3.Scale(sgn, holeAxis)`），
否则「孔轴朝哪、装饰朝哪」两个约束会在镜像那一维上解反。
自查判据：左右件的 `localPosition` 应当 x 反号、`localEuler.y` 应当互补到 360°。
实测修好前是 57.27° / 46.05°（不对称），修好后 313.90° / 46.05°（精确镜像）。
