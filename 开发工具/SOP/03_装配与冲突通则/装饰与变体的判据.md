# 装饰与变体的判据：包围盒答不了，要逐顶点量

> 从 [`03_装配与冲突通则.md`](../03_装配与冲突通则.md) 拆出的子页。接手自「装饰还是变体」一节的推导与证据；触发、问与接线取舍仍留主页。

### 答错了怎么办

**包围盒答不了这个问题。** 我用「体积比 0.76 + 中心距 1 cm」判成了变体 ——
一个**沿着本体分布**的装饰（花绕着耳朵一圈），包围盒和本体几乎重合，
和"同位置的另一个版本"在包围盒上**不可区分**。

**判据用逐顶点最近距离**：把 B 的每个顶点找 A 上最近的顶点，取距离的**中位数**。

| 中位距离 | 判定 |
|---|---|
| **< 2 mm** | 变体 —— 两件几乎共面，是同一块几何的两个版本 |
| **> 5 mm** | 装饰 —— B 悬在 A 之外/之上 |

**辅助判据（更便宜，先跑）**：
- **同一个源 FBX + 完全相同的骨列表 + 只有材质不同** → 几乎必然是**色变体**
- 顶点数、三角数**完全相同** → 变体
- 名字里带 `_White` / `_PINK` / `_A` / `_B` 这种成对后缀 → 变体的强信号（但**只是信号，仍要量**）

### 证据（工程C · Acc_GothicRoseFox，一正一反两个样本）

**判成装饰（正确）**：`Rose_Ears → Ears` 逐顶点最近距离**中位 11.7 mm**，
`Roses_Tail → Tail` **中位 34.8 mm**。作者确认：「这个部件不是变体，而是装饰」「Rose 是 Ear 的装饰」。
→ 改成同开。

**判成变体（正确）**：同一目录里另有「白 / 粉」两套耳尾 ——
**同一个网格文件、完全相同的骨骼、包围盒只差 1 cm，只有材质不同（白 vs 粉）**。
之前有一档把四件**全部打开**，白耳与粉耳互相穿插。→ 必须互斥。

**两个样本正好构成对照**：都是"位置几乎重合的两件"，包围盒判据对两者给出**相同的答案**，
逐顶点距离判据给出**相反且正确**的答案。判据要选**能区分已知正反例**的那个。
